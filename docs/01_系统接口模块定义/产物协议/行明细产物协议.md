# 行明细产物协议

## 1. 用途

本文件定义当前稳定的 row-shaped public payload。
它只覆盖历史列表与对比列表两类公开结果。

## 2. History Row

来源：
- `backend/core/services/experiment_query_service.py::list_experiments`

最小结构：

```json
{
  "exp_id": "exp_20260405_030220276_6afd",
  "label": "exp_20260405_030220276_6afd",
  "created_at": "2026-04-05T03:02:36.488069",
  "has_manifest": true,
  "has_core_artifacts": true,
  "asset_scope": "cn_a_equity",
  "asset_profile_id": "cn_a_equity_mainline",
  "market_profile_id": "cn_a_mainland_equity_market",
  "perf": {
    "cagr": 0.13307783712519594,
    "max_drawdown": -0.2751384763879182,
    "sharpe": 0.46753113430222226,
    "total_return": 4.528748964658465,
    "trades": 906
  }
}
```

## 3. Compare Item Row

来源：
- `backend/core/services/experiment_history_service.py::compare_experiments`

最小结构：

```json
{
  "exp_id": "exp_a",
  "label": "A",
  "created_at": "2026-03-08T01:00:00",
  "has_manifest": true,
  "has_core_artifacts": true,
  "perf": {
    "total_return": 0.3,
    "cagr": 0.1,
    "sharpe": 1.2,
    "max_drawdown": -0.2,
    "trades": 5
  },
  "nav": [
    {"date": "2024-01-01", "nav": 1.0},
    {"date": "2024-01-02", "nav": 1.1}
  ]
}
```

## 4. 结构约束

- `exp_id`、`label`、`perf` 不得删除
- 数值字段必须保持 `number|null`
- `nav` 必须是 `[{date, nav}]` 的列表
- compare payload 顶层只保留当前公开 row 结构
- 不再以 group-level rows 作为当前主路径表达

## 5. 兼容原则

- 可以新增字段
- 不可以把数值改成字符串
- 不可以返回 `NaN` / `Inf`
- 不可以用 PowerShell `@{...}` 风格伪 JSON
