## P0 进入规则

所有 P0 门禁变绿前，不得启动 P1 工作。

## P0 门禁

1. 默认测试收集必须成功。
   命令：`pytest -q --collect-only`
2. 脚本与 CLI 治理门禁必须通过。
   命令：`pytest -q tests/unit/test_script_surface_governance.py tests/unit/test_cli_main.py`
3. 核心边界门禁必须通过。
   命令：`pytest -q tests/unit/test_shared_helper_boundary.py`
4. 当前前端运行时边界门禁必须通过。
   命令：`pytest -q tests/unit/test_frontend_runtime_boundaries.py`
5. baseline 回归门禁必须基于当前重新锚定的正式产物通过。
   命令：`python -m backend.cli audit --target baseline_regression`

## P0 阻塞条件

- `pytest -q --collect-only` 失败，或退回到 import 阶段失败。
- 脚本表面治理或 CLI 表面治理测试失败。
- `backend/core` 重新直接依赖 `backend.api`、`backend.research`、`backend.cli` 或 `backend.scripts`。
- `backend/cli/managed` 重新依赖 `backend.scripts`，或直接执行顶层 `backend/scripts/*.py`。
- `backend/core/services/market_data_sync_records.py` 从纯同步运行记录存储退化为 runner 编排、调度器或数据刷新执行器。
- `backend/core/services/market_data_sync_freshness.py` 或 `backend/core/services/market_data_sync_status.py` 从纯计算/格式化 helper 退化为 runner 编排、调度器、数据库连接或数据刷新执行器。
- `backend/scripts/generated` 出现没有匹配 `research/studies/*.study.yaml` 的 wrapper，或当前 study 缺少对应的 `study_run` wrapper。
- `backend/scripts` 新增顶层完整实现但没有显式 legacy allowlist；或 `backend/api`、`backend/core`、`backend/cli` 依赖 `backend.scripts.ops`。
- `backend/api` 在 `tests/unit/test_shared_helper_boundary.py` 显式 legacy allowlist 之外新增直接 DB/env owner。
- 前端运行时边界测试失败。
- 前端引入展示层派生的运行时指标，但没有标记为 display-only，或没有声明 canonical truth 归后端所有。
- baseline 回归门禁报告无法解释的行为漂移。
- 任意漂移触及信号时点、成交时点、交易规则、资产池定义或 canonical artifact 协议，且不在合同允许的 drift 字段内。

## 允许漂移范围

foundation baseline 回归变更期间，只允许合同定义的 `allowed_drift_fields` 发生变化。baseline 对比中的其它变化默认都是阻塞项。
