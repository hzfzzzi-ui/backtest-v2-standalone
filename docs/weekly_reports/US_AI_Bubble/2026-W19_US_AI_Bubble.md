## 3. 泡沫评分模型

0 = 低风险，5 = 高泡沫 / 高风险。  
“真实需求兑现”和“龙头盈利质量”的分数表示未兑现或恶化风险。

| 因子 | 分数 | 判断 |
|---|---:|---|
| 估值泡沫 | 4.0 | 半导体和 AI 软件估值已不便宜 |
| 资本开支过热 | 5.0 | 大型云厂商 capex 全面上修 |
| 融资脆弱性 | 3.5 | neocloud、AI 私募和数据中心融资压力上升 |
| 真实需求未兑现风险 | 1.5 | 云 AI、芯片、API 使用仍强 |
| 供给过剩风险 | 3.0 | 2026-2027 数据中心和 GPU 供给集中释放 |
| 龙头盈利质量恶化风险 | 1.5 | NVDA、AVGO、MSFT、GOOGL 仍强，但云毛利承压 |
| 二三线公司脆弱性 | 3.5 | SMCI、DELL、AI 软件和 neocloud 对融资和订单敏感 |
| 信用市场压力 | 1.0 | HY / IG 利差未恶化 |
| 市场宽度恶化 | 3.5 | 涨势集中在 AI、半导体、大科技 |
| 监管和地缘风险 | 3.0 | 芯片出口、数据监管、电力审批、反垄断持续存在 |
| Mega IPO 和私募抽水压力 | 3.5 | OpenAI、Anthropic、SpaceX、CoreWeave 相关融资压力上升 |

**总分：34 / 55。**  
**比上周变化：无法验证上周基线；按本周新增信号估计 +2.5 分。**  
**当前更像：1999，带 2000Q1 顶部尾部风险。**

**最关键反证条件：**  
未来 2-3 周若 SOX 回撤小于 5% 后继续创新高、HY OAS 维持低位、AI 云收入继续上修、GPU 租赁价格不下跌、市场宽度扩散到非科技板块，则“顶部附近”判断失效。

## 5. 下周三种情景计划

### 情景一：继续上涨

**触发条件：** QQQ 日收 > 712.6；SOX 站稳 11780；VIX < 18.5；HY OAS < 3.0%；上涨家数扩散。  
**应该做什么：** 持有核心大票；强现金流仓位用移动止盈；只在回踩支撑时小幅加。  
**不能做什么：** 不在 SOX 单周大涨后加杠杆追 SMH / SOXX；不裸空强趋势。

### 情景二：顶部震荡

**触发条件：** QQQ 在 698-713 区间震荡；VIX 17-20；SOX 无法继续创新高；情绪拥挤但价格未跌破。  
**应该做什么：** 半导体和小票减 10-20%；用 QQQ / SMH put spread 或 collar；二线 AI 股止盈。  
**不能做什么：** 不清空全部核心大票；不做无触发条件的全市场做空。

### 情景三：下跌或泡沫破裂初期

**触发条件：** QQQ 日收 < 698 或 SOX 日收 < 11160；同时 VIX > 20 / VVIX > 105；HY OAS > 3.25% 或单周扩大 > 30bp。  
**应该做什么：** 高 beta / 小票 / 二线 AI 降仓 30-50%；买 QQQ / SMH put 或 put spread；资金转向短债 / 现金类防守仓位。  
**不能做什么：** 不摊平亏损 neocloud、二线 AI 基建、弱软件；不把信用利差扩大解释成普通回调。
