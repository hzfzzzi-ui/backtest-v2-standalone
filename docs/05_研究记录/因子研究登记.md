# 因子研究登记

当前状态：本登记表记录现有代码 catalog 与 study YAML 的对应关系，用于审计研究覆盖面。它不改变任何 baseline、信号时点、成交时点、资产池、组合构建或防守层逻辑。

## 1. 登记口径

| 字段 | 含义 |
|---|---|
| 研究面 | 因子或状态分数研究面的稳定名称 |
| 当前状态 | 当前仅表示登记状态，不表示已进入 baseline |
| 代码来源 | factor/score catalog 模块 |
| study 定义 | 对应 `research/studies` YAML |
| 因子或分数 | 当前登记的 factor_id 或 score_id |
| 备注 | 研究约束、风险或缺口 |

状态含义：

- `registered_research_surface`：已有 catalog 与 real mainline study，可审计但不自动进入 baseline。
- `demo_only`：仅演示或样例，不得作为正式结论。
- `derived_state_surface`：账户/市场状态分数研究面，不等同于交易因子。
- `needs_journal_link`：已有定义但本登记表尚未绑定具体结论记录。

- 多数因子研究面已经有 catalog 和 study YAML，但登记表尚未绑定具体 `research/study_journal` 结论文件。
- `a_share_moneyflow_divergence_min10` 仍是专题 study，尚未决定是否进入正式 moneyflow factor catalog。
- 部分历史 shadow/AB 研究仍散落在 `research/studies/cn_stock*`，未统一映射到因子研究登记。
- 新增因子时缺少自动检查，后续应由测试保证 catalog、study YAML 和登记表三者一致。
