# A股个股子系统策略思路

## 0. 文档定位

本文档定义 A 股个股子系统的正式策略语义。

本文档只回答四件事：

1. 个股子系统在当前系统里承担什么职责
2. 个股子系统当前实际在做什么交易
3. 个股子系统与整体风控边界的关系是什么
4. 哪些做法明确不属于当前正式个股主线

本文档不讨论代码实现与参数逐条抄录。

## 1. 正式定位

A 股个股子系统当前的正式定位是：

**在统一风险边界内承担 A 股主要 alpha 获取职责的主收益子系统。**

它当前是：

- 当前 A 股主收益引擎
- 正式基线收益锚点的承载层

它不是：

- 全组合总控
- 独立状态机
- 多资产总配置器
- ETF 子系统的替代品

## 2. 当前交易目标

当前个股子系统的交易目标，不是去预测短期波动极值，而是：

- 在趋势环境里找出更强的股票
- 在风险允许时参与趋势延续
- 在环境恶化时尽快降低低质量风险暴露

因此它更接近：

**趋势突破型个股 alpha 系统**

而不是：

- 左侧价值抄底系统
- 纯均值回归系统
- 高频轮动系统

## 3. 当前正式主线的核心思路

当前正式个股主线可以概括为：

**以趋势突破为主骨架，以相对强弱和残差强度做强化，在统一风险预算下运行。**

交易上可以分成三层理解：

### 3.1 先做股票池约束

当前正式股票池不是全市场无约束扫描，而是先做基本可交易性筛选。

正式主线当前强调：

- 动态成分股范围
- 剔除 ST
- 剔除停牌
- 要求一定上市天数
- 要求足够成交额
- 剔除过低价股票

这一步的目的不是提升收益上限，而是先过滤掉明显不适合正式主线的标的。

### 3.2 再做趋势确认

当前主线的买入基础不是“跌多了便宜”，而是“趋势结构已经转强”。

因此主线交易语义是：

- 突破优先
- 趋势质量优先
- 不做无确认的逆势抢反弹

它本质上是做：

**强者恒强的趋势延续**

而不是做：

**跌深反弹的左侧博弈**

### 3.3 最后做强中选强

在趋势主骨架之上，当前正式主线还会做进一步优选。

当前正式个股主线的一个关键特点是：

- 更强调残差强度
- 更强调相对行业/基准的独立强势

所以它不是简单地“谁涨得多就买谁”，而是更看重：

- 趋势是否真实成立
- 相对强势是否有独立性
- 当前环境下是否属于高质量强势股

## 4. 当前退出与收缩逻辑

当前个股子系统不是只会买入，也非常强调退出纪律。

正式主线当前明确包含：

- 趋势破坏后的退出
- 回撤与移动止损
- 低点破位退出
- 风险环境恶化时的风险收缩退出
- 盈利前阶段突破失败时的提前退出

这意味着：

- 它不是“只要买进就长期死扛”
- 也不是“只依赖一个固定止损”

当前正式主线更像：

**先争取趋势收益，再在趋势失真或环境恶化时尽快退出。**

## 5. 当前与整体风控的关系

个股子系统不能自己决定今天想开多少风险。

它必须服从整体风险边界，包括：

- 当前市场状态
- 总风险预算
- 仓位上限
- 回撤收缩
- 是否允许继续新增风险

因此当前个股主线虽然是收益引擎，但不是无限制进攻引擎。

更直白地说：

- 环境好时，它负责积极获取收益
- 环境差时，它必须主动降速

## 6. 当前交易风格特征

如果用交易者能直接感受到的话来概括，当前个股主线有这些明显特征：

- 偏趋势，不偏抄底
- 偏选强，不偏摊大饼
- 偏纪律退出，不偏长期死拿
- 偏环境适配，不偏无条件持续开仓

所以它在弱环境里更常见的表现是：

- 降低新开仓
- 保留更少、更强的持仓
- 提高退出与收缩的优先级

## 7. 当前明确不属于正式主线的做法

以下内容明确不属于当前正式个股主线：

- 左侧蓝筹抄底已经正式上线
- 价值卫星已经并入正式主收益主线
- 个股子系统自行定义总风险预算
- 个股子系统脱离市场状态独立运行
- 多资产统一配置职责由个股子系统承担

## 8. 对交易者的一句话总结

当前 A 股个股子系统的真实交易风格是：

**在统一风控下做趋势突破、做相对强势、做高质量延续，不做左侧抄底。**
