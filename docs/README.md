# 文档总览

当前仓库的正式文档入口统一收敛到 `docs/`。当前状态不是所有文件都已经完成重排；本 README 先定义阅读入口和文档分层，避免把给人看的说明、给机器/测试看的合同、研究记录和历史重构材料混在一起使用。

## 1. 当前主入口

1. [01_系统接口模块定义](./01_系统接口模块定义/README.md)：接口、模块边界、产物协议、架构守门
2. [02_系统架构设计](./02_系统架构设计/README.md)：系统架构、运行机制、数据库、基线与 runbook
3. [03_CTA面向交易者的策略](./03_CTA面向交易者的策略/README.md)：面向人的策略语义表达
4. [04_重构思路](./04_重构思路/README.md)：迁移路线、问题判断和历史演进材料
5. [05_研究记录](./05_研究记录/README.md)：study 研究索引、因子研究登记和研究记录归属
6. [product_launch](./product_launch/README.md)：上线准备、产品边界和 release gap 清单

## 2. 文档类型

文档分工：

| 类型 | 面向对象 | 典型路径 | 约束 |
|---|---|---|---|
| 人读说明 | 用户、研究者、维护者 | `README.md`、`03_CTA面向交易者的策略/*`、`product_launch/*.md` | 可以解释背景，但不得覆盖正式合同 |
| 合同/准机器文档 | 测试、CLI、实现者 | `01_系统接口模块定义/产物协议/*`、`02_系统架构设计/数据库/*_contract.md`、`product_launch/contracts/*` | 必须稳定、可校验、少叙事 |
| 机器执行材料 | 数据库或运维执行 | `02_系统架构设计/数据库/*.sql`、`*_runbook.md` | 必须写清适用范围、回滚方式和执行前置条件 |
| 研究记录 | 研究者、审计者 | `05_研究记录/*`、`research/studies/*`、`research/study_journal/*` | 必须记录 study、因子、窗口、状态和结论位置 |
| 历史/重构材料 | 架构治理者 | `04_重构思路/*` | 只记录方向和历史判断，不作为当前实现真相 |

更细的分层规则见 [文档分层与归属规则](./DOCS_GOVERNANCE.md)。

约束：

- 根目录只保留 [AGENTS.md](../AGENTS.md) 作为最高优先级协作规则
- `01` 和 `02` 优先表达当前正式真相，不承载历史迁移叙事
- `04` 可以记录重构目标和迁移路线，但不得反向覆盖 `01` / `02`
- `05` 记录研究索引和因子登记，不替代 `research/studies` 的 study YAML 和 `research/study_journal` 的结论记录
- `product_launch` 记录上线准备和缺口，不等同于生产 READY 声明
- `outputs/` 属于运行产物路径，不作为源码或正式文档真相来源
