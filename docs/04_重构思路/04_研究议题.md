# 04_研究议题

## 1. 当前值得研究的问题

### 1.1 账户级预算是否应强于固定 `50/50`

重点不是否定静态 `50/50`，而是判断：

- 当系统已有状态机与弱势处理逻辑时
- 是否应由账户层先给各 sleeve 预算

### 1.2 ETF 是否应在语义上拆成 defense / core beta

当前 ETF 同时承担多个角色，研究重点应是：

- 先拆预算语义与 explain 语义
- 再决定是否拆 runtime 实现

### 1.3 状态切换时是否应显式释放现金

当前弱势下经常出现：

- 有目标
- 有资产
- 但无可用现金

研究重点应是：

- 状态切换时库存如何调整
- defense / accumulation 的现金来源如何定义

### 1.4 弱势左侧应如何约束

应继续坚持：

- 只在弱势环境
- 只在核心宽基
- 只用小预算
- 以小额、分段、可解释方式累积

---

## 2. 当前不建议优先做的问题

以下问题当前不应作为第一优先级：

- 继续微调 stock alpha 参数
- 把弱势左侧推广到个股
- 同时改 regime、预算、执行三层
- 为了追 CAGR 牺牲 explain 与审计稳定性

---

## 3. 判断研究是否值得继续的标准

一个方向值得继续推进，至少应满足：

1. 行为更符合账户级直觉
2. explain 更强，不是更弱
3. 可归因，不是混合大改
4. execution feasibility 更强，不是更依赖补丁
5. 不破坏现有正式回归与 replay 稳定性

---

## 4. 当前建议的研究起点

如果从当前系统继续往前走，最建议先研究的是：

`Account Allocator Shadow Mode`

原因：

- 风险最可控
- 不直接改主线行为
- 能先把账户级真相做出来
- 便于后续判断预算是否值得上收
