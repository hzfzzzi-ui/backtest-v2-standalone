## ADDED Requirements

### Requirement: Watch combo AB MUST use unified runtime NAV
The watch combo AB MUST run through the unified stock+ETF runtime and build combo NAV from generated component NAVs.

#### Scenario: Watch candidate runs
- **WHEN** a watch combo AB candidate is executed
- **THEN** the stock component MUST run through the normal stock runtime
- **AND** the ETF component MUST run through the normal ETF runtime
- **AND** the combo NAV MUST be generated by the unified combo runtime
- **AND** the study MUST NOT use `precomputed_component_results`

### Requirement: Watch combo AB MUST isolate watch timing
The watch combo AB MUST only change stock component D5 strategy params needed for immediate or watch behavior.

#### Scenario: Watch payload is built
- **WHEN** a `HC_D5_WATCH_DAY5_COMBO` or `HC_D5_WATCH_DAY10_COMBO` payload is materialized
- **THEN** ETF component runtime input MUST remain unchanged except window bounds
- **AND** stock universe, ranking, entry rules, execution timing, costs, and account allocator policy MUST remain unchanged except window bounds
- **AND** stock runtime `strategy.params` MUST include explicit High Chase D5 watch parameters

### Requirement: Watch combo conclusion MUST compare all candidates against B0
The combo conclusion MUST compare each non-B0 variant against same-window `B0_COMBO_V3_REPLAY`.

#### Scenario: Study results are analyzed
- **WHEN** B0 and one or more candidate exp ids exist for a window
- **THEN** the report MUST compare total return, CAGR, Sharpe, max drawdown, Calmar, trades, and D5-related exit counts for every candidate
- **AND** it MUST include stock and ETF component exp ids
- **AND** it MUST state continue, reject, or hold without promoting a baseline
