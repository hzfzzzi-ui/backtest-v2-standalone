## ADDED Requirements

### Requirement: Deep MAE combo AB MUST use unified runtime NAV
The deep MAE combo AB MUST run through the unified stock+ETF runtime and build combo NAV from generated component NAVs.

#### Scenario: Deep MAE candidate runs
- **WHEN** a deep MAE combo AB candidate is executed
- **THEN** the stock component MUST run through the normal stock runtime
- **AND** the ETF component MUST run through the normal ETF runtime
- **AND** combo NAV MUST be generated by the unified combo runtime
- **AND** the study MUST NOT use `precomputed_component_results`

### Requirement: Deep MAE combo AB MUST isolate MAE-depth behavior
The deep MAE combo AB MUST only change stock D5 MAE thresholds and watch-action parameters.

#### Scenario: Candidate payload is built
- **WHEN** a deep MAE variant is materialized
- **THEN** stock universe, ranking, entry rules, execution timing, costs, ETF sleeve, and account allocator policy MUST remain unchanged except window bounds
- **AND** ETF component runtime input MUST remain unchanged except window bounds
- **AND** stock runtime `strategy.params` MUST contain explicit D5 MAE-depth parameters

### Requirement: Deep MAE conclusion MUST compare all variants against same-window B0
The deep MAE conclusion MUST compare each candidate against same-window `B0_COMBO_V3_REPLAY`.

#### Scenario: Results are analyzed
- **WHEN** B0 and candidate exp ids exist for a window
- **THEN** the report MUST compare total return, CAGR, Sharpe, max drawdown, Calmar, trades, immediate D5 exit count, watch D5 exit count, and stock/ETF component exp ids
- **AND** it MUST state continue, reject, or hold without promoting a baseline
