## Why

当前系统已经具备完整的桌面研究平台与回测产物链路，但手机侧既没有安全入口，也没有面向半自动下单的轻量看板。用户现在需要在保留电脑端研究能力的前提下，通过私网 HTTP 地址从手机查看最新买卖指引，因此需要把“私网访问控制 + 手机信号看板”沉淀为独立变更，而不是继续堆叠在桌面工作台里。

## What Changes

- 新增手机专用看板入口 `/mobile`，与现有桌面研究平台首页解耦，默认只承载只读看板和半自动下单指引。
- 新增私网访问约束与登录能力，默认只允许本机、局域网或显式允许的私有主机访问手机端入口和手机端 API。
- 新增手机端会话认证接口，支持口令登录、会话校验和退出登录，不改变现有桌面端工作流。
- 新增手机看板聚合接口，基于最新实验产物、执行预览和市场快照输出“当前持仓、建议买入、建议卖出、风险摘要、实验摘要”。
- 保留桌面研究平台现有首页、结果工作台和实验 API 行为，不将手机端交互反向耦合到桌面端页面结构。

## Capabilities

### New Capabilities
- `private-mobile-access`: 为手机端入口提供私网 Host 限制、口令登录和会话校验能力。
- `mobile-signal-dashboard`: 提供手机专用看板页面与聚合 API，展示最新实验对应的买卖指引和运行摘要。

### Modified Capabilities

无。

## Impact

- 后端入口：`backend/main.py` 需要新增手机页面路由和私网访问限制中间件。
- 后端 API：`backend/api/endpoints/` 需要新增手机认证与看板聚合接口。
- 产物读取：需要复用 `outputs/experiments`、`outputs/market_snapshots` 与执行预览逻辑，补齐面向手机端的聚合层。
- 前端静态资源：`frontend/` 需要新增手机专用 HTML、CSS、JS 入口，不替换当前桌面研究平台。
- 配置与运维：需要新增手机访问口令、会话密钥、允许主机列表等环境变量说明。
